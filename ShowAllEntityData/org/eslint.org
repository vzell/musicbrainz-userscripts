   ="\udd17 Relationships"= (a lone surrogate); with =/u= it is left alone.
   Fix: add =u= to each regex, after checking that the class has no escapes
   =u= rejects (=\-= outside a class, for example). The userscript lines start at
   18888, 22958, 23604, 30149, 30520, …
