- *Source*: =docs/non-mb-coverage.json=, written by hand.
  - Sites hold their pageTypes. Each PT has an IP cell and an FRP cell: state, evidence, why, and a gap id.
  - A cell with "spec" evidence names the spec file and part of a test title.
  - There are readers, the three window sets, the site views and the windows.
  - Link families carry one route rule per site view (=here=, =tab=, =all=, =gap:G<n>=, with notes).
  - Gaps G1–G8.
- *Generator*: =scripts/build-coverage-report.py=, modelled on =build-changelog-pages.py=.
  - It writes both outputs. =--check= and =--selftest= work as there.
  - It never prints a timestamp, SHA or version, so a version bump does not make the report stale.
- *What =--check= compares against the userscript*:
  - every =pageDefinitions= entry with a =host:=: type, tableMode and order;
  - every =_DP_SITES= key with its =setting= and =extRoot=;
  - the =_EXT_READERS= ids in order;
  - the three =_DP_WIN_*= sets and =_MB_FOREIGN_POP_HOST='s host flags;
  - each host flag, gate and preview setting (=configSchema= keys);
  - each topic doc;
  - each spec file and its test title;
  - each gap's code symbols.
- *Planted defects*: the selftest plants 23 defects in a small synthetic userscript and registry, and each one must be reported.
  - This replaces the =scripts/mutations/*.json= entry the plan named. =mutation-check.py= runs Playwright specs only, so it cannot check a Python generator.
