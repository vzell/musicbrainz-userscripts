** Background of the decisions above

1. *Ctrl+click.* Today Ctrl+click anywhere in the window opens a new tab (=_dpDrill()= bails on
   any modifier), so tag links need their own branch before =_dpDrill()='s modifier check.
2. *Image history.* =…/images/update= is an edit page and needs the Discogs login. Link previews
   send external requests =anonymous= (detail-pages rule); on discogs.com the page is
   same-origin and everything is there.
3. *Documentation.* =/search?type=doc= is rendered client-side by Google's custom search, so
   there is no HTML to read. Probe =wiki.musicbrainz.org/api.php?action=query&list=search=
   (CLAUDE.md probe rule) and record the result here.
