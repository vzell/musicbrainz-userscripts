** DONE solution

Expanded sections now stay in view while you scroll right, not just their header bars. Commit 285c58f is pushed on
feature/sticky-section-bodies, not merged; the full fixture suite passes (867/867).

What happens now:
- (a) Section content: whatever an expanded section shows under its header stays in place, the same content that
  expanding and collapsing the section shows and hides. On release-tracks that's the Credits URL lists; on series pages,
  the Relationships table and the Annotation.
- (b) Release / Release group lines: they move with the Credits content, which stays put, so they're effectively sticky
  as well.
- The tracklist is unaffected: its sub-table header bars stay pinned and the data tables scroll, as before. Expanding a
  section takes effect immediately, by click, Ctrl+click "toggle all", keyboard or master toggle, and collapsing it
  releases the content again.

Why it scrolled away: the feature only ever pinned header bars, never section content. It also refused to pin anything
containing a table, a rule meant for the data tables that caught Credits' small link tables too. And expanding a section
didn't trigger a re-check.

Scope choice: this pins the content of every section other than the one holding the data tables. You asked for the
sections above the global filter. On release pages that's the same set, because Credits is moved above Tracklist and the
later sections live in the sidebar, which is never pinned. If you've turned off the setting that moves trailing sections
above the table, sections left below it would be pinned too. Say if you want that narrowed.

Checks:
- Three new tests: Credits on the release fixture, the bare Relationships table on the series fixture, and data tables never pinned.
- Three new planted defects, all caught. One of them removes all three data-table safeguards at once, because each covers for the others, so removing just one would go unnoticed.
- Performance on artist-events is unchanged (settled sort equal; post-render work 1043 vs 143 ms with the feature off, as before).

The help file, changelog draft (WIP.1), DEBUG-NOTES.md, tests/MEASUREMENTS.org and the snapshot registry are
updated. Your uncommitted edits to org/sticky-areas.org are left alone; that file has a trailing blank line, which is
why my whitespace check skips it.
