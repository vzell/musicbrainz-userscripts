* TODO Is it possible to muliselect options under the "WARNING" and "ERROR" menu buttons - [Image #5]

Yes, you can tick several rows, but each click closes the menu, so you have to reopen it for every extra one. The closing is deliberate: any click on a menu row runs setTimeout(close, 0) in createToolbarMenu().

How the ticked rows combine depends on where each warning sits:

- Same column: the rows are 📊 ticks in that column, so they combine as OR. You see rows with either warning.
- Different columns: ticks in different columns combine as AND. You only see rows with both.
- Warning in several columns at once: the menu falls back to a page-wide row filter and shows a chip, like "ASCII punctuation in title" in your screenshot. That happens here because the title-style warnings sit in both Name and Release groups. These row filters also combine as AND. So adding "Title not in MB title case" on that page would show only rows with both problems, not rows with either.

That AND is probably not what you'd expect from a multi-select list of warnings. Two changes would make it work the way the screenshot suggests:

1. Keep the menu open on a warning row click (checkbox rows only; "Clear" and "Check title style" would still close it). Then you can tick several in one go.
2. Make ticked rows within one menu combine as OR, meaning rows with any of the ticked warnings, while the menus still AND with your other filters. This changes the existing semantics, which findings-menus.spec.js pins.

Both are a few lines in _buildFindingMenuRows()/_toggleFinding() and the row-filter test in testRowMatch(), plus spec changes. Do you want one or both? If both, should OR also apply across WARNING and ERROR, or only within one menu?
