Tags kept on a show's On stage page

Brucebase keeps a page's tags under 512 characters, and a show's cast tags live on its separate On stage page (sometimes two or three of them). Today the show page head and the preview window show only the show page's own tags. Mockup with real tags from the 2026-11-13 mirror.

Show
Network
1 · Show page, the head's Tags card (bb-event)
2 · Preview window (Space on a show link, on Brucebase or MusicBrainz)
What it does
  • The show page's own tags look as they do today. Tags from an On stage page get a dashed outline and a ↪ mark. Hover or tap one to see which page it is kept on.
  • The count includes them, and the line under the tags names each On stage page with how many tags it adds.
  • Tags that already appear on the show page are shown once. The onstage tag counts once too.
  • The On stage pages are read only when the show page has an On Stage tab. The next page (-2, -3) is read only while the page before it is nearly full (over 450 of 512 characters).
  • On the show page, the pages are read when you press the button, together with the rest of the page. In the preview window they are read after the card, through the same queue, and each one is cached like every other page.
  • The year table is unchanged: its ▶ Pages columns show no tags.
