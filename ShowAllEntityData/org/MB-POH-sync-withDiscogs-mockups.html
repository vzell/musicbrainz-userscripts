Part 1 · Discogs windows

A third sort state: initial order

Every sortable header has three states. In the initial state the rows are in the order Discogs (or MusicBrainz) gives them, and the header shows a dimmed ⇅. One click cycle everywhere: ⇅ → ▲ → ▼ → ⇅. Today the Sublabels table only toggles ▲/▼, and the other tables show nothing in the initial state.

Part 5

Open questions

  1. Ctrl+click on a genre. You asked for a click to open the tag and Ctrl+click to open your own tag. Ctrl+click in the window opens a new tab today. Proposal: on tag links only, Ctrl opens /user/<you>/tag/<genre> in the window; middle-click and Shift+click still open a new tab, and the foot line says so.
  2. Image history from musicbrainz.org. Without the Discogs login: position, type and size only. Is that enough, or should the window send you to discogs.com?
  3. Annotation version. It was on the list without a wish. Leave it as it is?
  4. Documentation. MusicBrainz's documentation search is drawn by Google in the browser, so there is no page to read. If the wiki's own search API answers (to be probed first), the window lists the hits and opens /doc/… pages inline; otherwise only /doc/… links get a reader.
