** DONE Decisions (2026-09-27) and what shipped

Both "Show all " and plain "Show " are stripped, but only from what's
*painted* on the button — the fix is a single new line in the one render
loop every =pageDefinitions[].buttons[].label= funnels through
(=buttonsToRender.forEach=, branch =${ShowAllEntityData.user.js}=), computing
a display-only stripped label right before the existing =🧮N= mnemonic
prefix. =conf.label= itself, and therefore =eb.dataset.label=, is left
untouched, which is what keeps roughly 100 existing Playwright fixture specs
(=button[data-label="Show all …"]=) passing unmodified — only the tooltip's
=.includes('Show all')= check and the mnemonic-prefix logic read
=conf.label= after this point, and neither needed to change.

The "(xxxxx) " note above turned out to just be pointing at this TODO's own
=LowDataQualityReleases= mention — clarified as: use the bracket text from
the *next* TODO's mockup for that page (=[Unfiltered] [Subscribed Only]=).
So the =report-detail=/=report-multiple-linked= pair got a small special-case
rename at the source (=Show all (unfiltered)=/=Show all (subscribed only)=
→ =Unfiltered=/=Subscribed Only=) rather than relying on the generic strip,
which alone would have left the parens and lower-case intact.

Also resynced: the three example button strings quoted in
=ShowAllEntityData_HELP.md=, and the two fixture specs that hardcoded the old
report =data-label= as a click selector.

The "more action button consolidation" TODO below (bold group-label heading
before the button row, e.g. =Subscriptions:=, and bespoke short labels for
6 named pages) is deliberately NOT part of this — it also implies dropping
the =🧮= mnemonic on those pages, which needs its own design pass.

=WIP.1='s prefix strip — =conf.label=/=eb.dataset.label= untouched) covers all

** DONE Decisions (2026-09-27) and what shipped

The =buttonGroupLabel= heading (see above) now renders as a =" | "= divider —
reusing =uiButtonDividerCSS()=, the same style already used before the 📦
Data ▾ menu — followed by a =<strong>= at =font-size:0.65em= rather than the
native =h1='s full size, so it reads as a caption under/after the entity name,
not a second title. Applies to all three =buttonGroupLabel= pages generically
(one shared code path), confirmed live by the user on both the Releases and
RGs pages.

* DONE rich tooltips for the buttons

Not originally in this file — added on request once buttons started losing
their descriptive context to =shortLabel=. Every action button now gets a
styled HTML hover tooltip (=data-mbtt=, shown via the existing
=#mb-stat-tooltip= popup the row-count stat already used — its delegation was
generalised from =.mb-row-count-stat= to any =[data-mbtt]= element) showing
the full un-shortened label, the fetch description, and the Ctrl-M shortcut.
The native =title= is kept as an accessible fallback and is what the popup
temporarily blanks while hovering. This also fixed a pre-existing gap where
several buttons (subscriptions, tag upvote/downvote, aliases, …) had no
tooltip — and therefore no shortcut hint either — at all.
