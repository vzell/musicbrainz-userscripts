Findings that change the design:

- *springsteenlyrics*: the list's cover IS the item page's cover (same URL). The scans
  exist only on the item page. The list already prints "artwork available" (the Artwork
  column: 35 of 50 rows on =sl-bootlegs-page1=), so a row without it needs no request.
  A brucelegs item page also shows the covers of related items (the same show's other
  releases): only the card's own =.col-md-2 img= is the cover — =_dpParseSl= already
  does that.
- *jungleland*: the labels are in the file names (=front=, =back=, =cd1…=,
  =booklet1…=) and map onto MusicBrainz's types (Front, Back, Medium, Booklet), so the
  card can use the grouped layout and type chips.
- *brucespringsteen.it*: at most one photo, often none (all four CD-R pages); thumb =
  full. Presence is known only after the page is read → a three-state cell.
- *brucebase*: the gig pages hold typed folders — =gallery:<gig>= (photos),
  =files:ticket-YYYY=, =files:pass-YYYY=, =news:<gig>= (clippings) — which match the year
  page's Media icons (Photo, Ticket, Memorabilia, News). Every page also carries the
  side bar's promo image (=files:artwork-disco/disco_livefromasburypark_rsd26.jpg=,
  linking =/retail:=); a reader must skip it. =_dpParseBb= reads only =/song:= pages and
  no images; a =/gig:= reader is new.

*** Implementation outline (as planned; phases 1–2 landed, see their sections for what differs)

1. One generic path for foreign rows, folding Discogs' in: a ctx per host
   (={key, column, external: true, imagesCache}=), records built from the parsed detail
   record =_dpGet()= already caches (same IndexedDB, same 1.1 s spacing as the detail
   preview), a card case in =_mbttResolve()= + =_ART_CARD_FNS=, one window-capture click
   handler keyed on a data attribute (plain left click only; =_dgThumbClick()= moves into
   it).
2. Parsers: =_dpParseSl= / =_dpParseJl= / =_dpParseBs= already return cover and scans; JL
   needs its label → type map; a new =/gig:= reader and image extraction for =/song:=
   pages (skip the promo image and the 32 px icons). Bump =_DP_PARSER_VERSION=.
3. Cells: S1 wires the existing =img.mb-sl-cover=; J1/K1 add a deferred column whose late
   writes reach the master rows (=_findMasterRowByIdx()=) and owe the four filter-cache
   duties (docs/claude/filter-and-cache-invariants.md); a glyph goes into
   =_CLEAN_STRIP_SEL=.
4. =_artCardCoreHtml()=: =referrerpolicy="no-referrer"= on its tiles for an external
   ctx (missing today; only Discogs' loading box sets it).
5. Settings =sa_sl_tip_images=, =sa_jl_tip_images=, =sa_bs_tip_images=,
   =sa_bb_tip_images= (default on, inside each site's opt-in).
6. Specs per site modelled on =tests/fixtures/discogs-image-card.spec.js= (card states,
   click → viewer, Shift+← → over filtered rows, Ctrl-click keeps the link, zero requests
   at render); new fixtures for the item pages from =debug/foreign-images/=. MusicBrainz
   fixture suite before merge; perf: nothing on the MusicBrainz hot path, nothing at
   render on the foreign hosts.
