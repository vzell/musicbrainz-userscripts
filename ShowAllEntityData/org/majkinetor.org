*** Shared runtime (all scripts)

**** Request gate — =dev/net/mb-gate.mjs=, inlined as ST-NET (EH:59-284)

- *State*: cross-tab, in localStorage =mbu:mb-gate= ={tat, cool, hot, lead, leadUntil}=, read-modify-written under a
  Web Lock =navigator.locks.request('mbu-mb-gate')= (3 s abort, unlocked fallback). Only =/ws/2= is gated (=mbnGated=).
- *Pacing*: GCRA-style, =MBN_GAP=1000= ms. Background requests may burst to =MBN_BURST=3=; foreground requests book at
  once. A slot is reserved first, then waited for in 250 ms slices so cancellation is prompt (=mbnSlot= ≈94).
- *Transport* (since =1df6193=): the gate's own requests go through =GM_xmlhttpRequest= with a
  =User-Agent= header (=mbnWsFetch=; EH got =@connect musicbrainz.org=), no longer the page's =fetch()=.
- *Lead*: =mbnLead(token, ms)= (≈126), capped at 10 s. The tab whose page is loading leads, and every other script and
  tab waits. A hidden tab never leads.
- *429/503* (=mbnAnswer= ≈132):
  - honours =Retry-After= (seconds or a date);
  - =hot= rises by one per throttle /episode/ (max 6) and resets after 30 s of quiet;
  - hold = =min(max(1 s, RA) × max(1, hot), 60 s)=, written to the shared =cool=, so *every script in every tab holds*;
  - =mbnFetch= retries up to 4 times.
- *Browser check*: =mbnIsCheck= / =mbnReverify= (≈193-243) pass "Verifying your browser" in a hidden 1×1 same-origin
  iframe, then retry.
- *SAED today*: a per-tab, in-memory slot (=_relAwaitRateSlot=, 1100 ms), =_ws2GetJson= transient retry,
  =_parseRetryAfterMs=. =_mbIsBrowserCheck= only tells the user to open the page.
- *Verdict*: *adopt*. Booking SAED's ws/2 requests in the same =mbu:mb-gate= key makes SAED pace together with all of
  majkinetor's scripts. Also take the lead idea, the per-episode escalation and the iframe re-verify. SAED's main fetch
  is native HTML, which this gate does not cover; ws/2-heavy columns (Relationships, popups, Discogs MB column) are.

**** Corner launchers / dock — =dev/ui/ui-components.mjs= (=mbuDock= UI:794, =mbuDockItem= UI:1082, =mbRestackCorner= UI:1110)

- *Launcher attributes*: =data-mb-corner="br|bl|tr|tl"=, =-order=, =-label=, =-paths= (a regex on the path),

**** Viewer mechanics (the part that matters for 4.)

- *Start (EH:12539-12549)*: if =S.on= (*default =true=*, EH:4017 =S= object), it injects =#eh-hide= and calls
  =prefetch(PAGE_ID)= at document-start. =start()= (EH:12205) records =mbBody = document.body=, puts up the
  launcher, then runs =setTimeout(() => setOn(S.on && !off), 0)=. The tick is there so String Theory members can
  read the native page first.
- *=setOn(on)= (EH:11487)*:
  - *on*: =documentElement.insertBefore(ehBody, mbBody); mbBody.hidden = true=. From then on, *=document.body= is
    EH's body*. MB's body stays in the document, hidden (#853).

  - Only =:scope > [data-mb-corner]= children move between the bodies.
  - Turning off after navigating inside EH sets =sessionStorage 'eh-off'= and *reloads* the page (EH:11490).
  - The on/off choice is saved (=switchOn= → GM =view.on=), so the next page opens the same way.
- *Navigation*: =pushState= only through =ehPush= (EH:12245); =navTo= (EH:10425) maps a URL to a view;
  =popstate= into something EH can't show, or with EH off, reloads (EH:11483).
