*** Shared runtime (all scripts)

**** Request gate — =dev/net/mb-gate.mjs=, inlined as ST-NET (EH:59-284)

- *State*: cross-tab, in localStorage =mbu:mb-gate= ={tat, cool, hot, lead, leadUntil}=, read-modify-written under a
  Web Lock =navigator.locks.request('mbu-mb-gate')= (3 s abort, unlocked fallback). Only =/ws/2= is gated (=mbnGated=).
- *Pacing*: GCRA-style, =MBN_GAP=1000= ms. Background requests may burst to =MBN_BURST=3=; foreground requests book at
  once. A slot is reserved first, then waited for in 250 ms slices so cancellation is prompt (=mbnSlot= ≈94).
- *Transport* (since =1df6193=): the gate's own requests go through =GM_xmlhttpRequest= with a
  =User-Agent= header (=mbnWsFetch=; EH got =@connect musicbrainz.org=), no longer the page's =fetch()=.
- *Lead*: =mbnLead(token, ms)= (≈126), capped at 10 s. The tab whose page is loading leads, and every other script and
  tab waits. A hidden tab never leads.
- *429/503* (=mbnAnswer= ≈132):
  - honours =Retry-After= (seconds or a date);
  - =hot= rises by one per throttle /episode/ (max 6) and resets after 30 s of quiet;
  - hold = =min(max(1 s, RA) × max(1, hot), 60 s)=, written to the shared =cool=, so *every script in every tab holds*;
  - =mbnFetch= retries up to 4 times.
- *Browser check*: =mbnIsCheck= / =mbnReverify= (≈193-243) pass "Verifying your browser" in a hidden 1×1 same-origin
  iframe, then retry.
- *SAED today*: a per-tab, in-memory slot (=_relAwaitRateSlot=, 1100 ms), =_ws2GetJson= transient retry,
  =_parseRetryAfterMs=. =_mbIsBrowserCheck= only tells the user to open the page.
- *Verdict*: *adopt*. Booking SAED's ws/2 requests in the same =mbu:mb-gate= key makes SAED pace together with all of
  majkinetor's scripts. Also take the lead idea, the per-episode escalation and the iframe re-verify. SAED's main fetch
  is native HTML, which this gate does not cover; ws/2-heavy columns (Relationships, popups, Discogs MB column) are.

**** Corner launchers / dock — =dev/ui/ui-components.mjs= (=mbuDock= UI:794, =mbuDockItem= UI:1082, =mbRestackCorner= UI:1110)

- *Launcher attributes*: =data-mb-corner="br|bl|tr|tl"=, =-order=, =-label=, =-paths= (a regex on the path),
  =-dock="no|hide|only"=, =-status=.
- *Layout*: =mbRestackCorner= stacks them with inline styles. It listens on visualViewport, resize and a

- *Folding*: while =<html data-mbu-dock>= (EH shows) or =data-mbu-st= (ST present) is set, they fold behind one
  =#mbu-dock= button appended to =<html>=, outside either body.
- *SAED*: takes part in none of this. Its toasts sit at =bottom:20px; right:20px=, the same spot as Falcon and Fusion.
- *Your TODO "no icons in the lower right corner" on the FRP*: do what MC does (MC:988). While the FRP shows, set a

  =html.<cls> :is([data-mb-corner], #mbu-dock, #mbu-dock-shelf, .mbu-dock-win){display:none!important}=.
  The =!important= is needed because the restack writes inline styles. Alternatively, tag our own toasts
  =data-mb-corner="br" data-mb-corner-dock="no"= so they stack with the others instead of under them.

**** Logging — =mbuLog= (UI:1184-1810)

This is most likely what the org/TODO.org item "adapt the logging framework and orig page shine through from
majkinetor" means.

- *Use*: one logger per script, =LOG = mbuLog({name, version, key, history})=.
- *Levels*: error/warn/info/ok/debug; =LOG.cat()= categories; =LOG.pre= blocks kept as written.
- *Window*: floating, draggable and resizable, with a text filter and level/category chips, Clear, full screen, and
  *Copy as Markdown* (for issue reports).
- *Buffer*: a 20,000-line ring buffer; =mount(el)= embeds the viewer in a panel.
- *Kept sessions*: in localStorage =<prefix><timestamp>=, the last 10. A session is kept when marked, or
  automatically at its first warning or error.
- *SAED today*: =Lib.debug/info/warn/error= (VZ_MBLibrary:217-271) writes styled console lines only.
- *Verdict*: *adopt* a ring buffer + viewer behind =Lib.*=, with SAED's debug channels as categories. That lets a
  user send us a log without opening DevTools.

**** "Orig page shine through" (the same org/TODO.org item)

Most likely EH's technique for a native page that must not flash:

- At document-start it injects =<style id=eh-hide>body{visibility:hidden!important}</style>= (EH:11304) and starts
  the page's own requests before DOMContentLoaded (=prefetch= EH:11011).
- It draws a skeleton matching the final layout (=skeleton= EH:10995).
- It removes the hide in =setOn=, and disables MB's stylesheets while EH shows (=mbSheets=).

SAED runs at document-idle and renders after a button press, so the equivalent would be: hide the native table
until our render replaces it, for the pageTypes that auto-render. That needs checking against the org/TODO.org notes on the "shine through" effect (under "on 'release-tracks'
PTs render the front image from the sidebar …" and "make the doubling of the IP information on non-MB PTs shine
through …").

- How: a =--mbu-theme= override; otherwise the body background's luminance (< 0.35 means dark).
- What it sets: =data-mbu-theme= on =<html>=.
- What it watches: the head, root and body, plus =prefers-color-scheme=.
- SAED reads =getComputedStyle(document.body).backgroundColor= once.
- *Verdict*: *adopt* the detection, or simply read =data-mbu-theme= when ST is present.

**** Settings sync (ST =sync*.js=)

- Back-ends: Dropbox (PKCE), Google Drive (=drive.file=), and WebDAV (ETag =If-Match=, 412 → merge).

- SAED has config export/import but no sync.
- *Verdict*: optional *adopt*, e.g. WebDAV for SAED's settings and filter history.

*** Event Horizon in depth

**** Viewer mechanics (the part that matters for 4.)

- *Start (EH:11302-11311)*: if =S.on= (*default =true=*, EH:3343 =S= object), it injects =#eh-hide= and calls
  =prefetch(PAGE_ID)= at document-start. =start()= (EH:10969) records =mbBody = document.body=, puts up the
  launcher, then runs =setTimeout(() => setOn(S.on && !off), 0)=. The tick is there so String Theory members can
  read the native page first.
- *=setOn(on)= (EH:10609)*:
  - *on*: =documentElement.insertBefore(ehBody, mbBody); mbBody.hidden = true=. From then on, *=document.body= is
    EH's body*. MB's body stays in the document, hidden (#853).
  - *off*: =ehBody.remove(); mbBody.hidden = false=.
  - Only =:scope > [data-mb-corner]= children move between the bodies.
  - Turning off after navigating inside EH sets =sessionStorage 'eh-off'= and *reloads* the page (EH:10612).
  - The on/off choice is saved (=switchOn= → GM =view.on=), so the next page opens the same way.
- *Navigation*: =pushState= only through =ehPush= (EH:11008); =navTo= (EH:9548) maps a URL to a view;
  =popstate= into something EH can't show, or with EH off, reloads (EH:10605).
- *Marks on =<html>=*: =data-mbu-page= (path + query), =data-mbu-release= (MBID), =data-mbu-dock=; ST adds
  =data-mbu-st=. Scripts that "follow EH" observe these (PC, IS, MC; ST starts members later through
  =data-mbu-page=).
- *Views*:
  - *own view*: home, all 12 entity root pages, tags, aliases, relationships, recordings, works, events,
    artists/labels subpages, user, collections, ratings, tag, search, history and single edits, cover/event art,
