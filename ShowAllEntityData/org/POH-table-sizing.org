*** Cause (confirmed in code, 9.99.1518)

Every table in the window sits in =div.mb-dg-vwrap=, and one rule gives it a fixed cap:

#+begin_src css
.mb-dp-dialog .mb-dg-vwrap { overflow: auto; max-height: 460px; border: 1px solid #d9cfbd; border-radius: 3px; background: #fff; }
#+end_src

Nothing in it depends on the window's height, so a taller window only adds empty paper under the
table. Grep anchors (line numbers drift):

** Design (approved 2026-10-31, branch =feat/poh-table-fill=)

Answer 2 is read as: the left column grows by D (grips, a dragged height sticks); left tables do not
fill the window by themselves. Say so if that is wrong.

*** A: the right column fills the window (=_dpPaneFit()=)

The right columns differ a lot (one List table; several Compact tables; tables inside
=details.mb-dp-sec= or Discogs =section.mb-dg-sec=). The mockup's pure-CSS flex chain only works when
the table is a direct child of the column, so A measures instead, which works for any nesting:

- Which column: the second =.mb-dp-col= of a two-column =.mb-dp-x= laid out side by side, holding a
  =.mb-dg-vwrap= with a table. One column (the =max-width: 640px= media query): A is off.
- Pane: that column gets =mb-dp-pane= — sticky at the top of the window body, =align-self: start=,
  =max-height: var(--mb-dp-pane-h)=, =overflow-y: auto= as the fallback.
- The LAST =.mb-dg-vwrap= in the pane fills (=mb-dp-fill=): =max(160px, paneH − rest of the pane)=.
  Other tables in the pane keep 460 px and get grips.
- Runs after every paint (before =data-mb-keep-scroll= positions are restored), on a window resize
  (a =ResizeObserver= on the body), and on =toggle=/=load= inside the body; one pass per frame.
- =.mb-rg-wtable-wrap= (=_mbPopTableHtml()=) has no height cap: out of scope.

*** D: grips under every other table

- Every =.mb-dg-vwrap= with a table that is not the fill table: left column, the pane's other tables,
  full-width sections, everything in the one-column layout. Only when the table scrolls or has a
  saved height.
- Key: =data-mb-keep-scroll=, else the closest =[data-mb-tbl]= id, with running parts folded
  (=tag-kind-<slug>= → =tag-kind=, =ratings-<n>= → =ratings=, =dg-a-<role>= → =dg-a=).
- Stored in one GM value =sa_dp_table_heights= ={ key: px }=, in the workspace export's geometry group.
- Drag (min 120 px, label "312 px · 14 of 52 rows"), double-click resets, ↑/↓ ±20 px, Esc cancels a
  drag without closing the window. Events delegated on the window body (repaints replace the grips).
