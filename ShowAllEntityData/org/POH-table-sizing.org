*** Cause (confirmed in code, 9.99.1518)

Every table in the window sits in =div.mb-dg-vwrap=, and one rule gives it a fixed cap:

#+begin_src css
.mb-dp-dialog .mb-dg-vwrap { overflow: auto; max-height: 460px; border: 1px solid #d9cfbd; border-radius: 3px; background: #fff; }
#+end_src

Nothing in it depends on the window's height, so a taller window only adds empty paper under the
table. Grep anchors (line numbers drift):

| Grep for                                               | What                                                                                                    |
|--------------------------------------------------------+---------------------------------------------------------------------------------------------------------|
| =.mb-dp-dialog .mb-dg-vwrap {=                         | the 460 px cap                                                                                          |
| =function _dpListTableHtml=                            | the window's List table: filter, chips, =div.mb-dp-tbl > div.mb-dg-vwrap= (setlist, RGs, releases, …)   |
| =function _dpCompactTableHtml= (box with =mb-dg-cwrap=) | the Compact tables (Discogs sublabels, …), same wrapper                                                 |
| =.mb-dp-dialog .mb-dp-x {=                             | the window body's two-column grid =minmax(0, .9fr) minmax(0, 1.1fr)=; one column under 640 px          |
| =.mb-dp-dialog .mb-dp-col=                             | a column (=min-width: 0=)                                                                                |
| =.mb-dp-dialog .mb-dp-area {=                          | the scrolling window body (=api.scrollArea=)                                                            |
| =placeholder: 'Filter the setlist: song, guests'=      | the event window's setlist (right column); a second setlist at =placeholder: 'Filter the setlist: song, cover, guest'= |
| =placeholder: 'Filter loaded release groups=           | the artist window's release groups (right column)                                                       |
| =data-mb-keep-scroll=                                  | the table's scroll position survives a re-render; must keep working                                     |

Other =mb-dg-vwrap= users: =.mb-pop-medtable= (release media), the Discogs versions table
(=data-mb-keep-scroll="dg-versions"=), the Discogs credits (=dg-a-<role>=).

*** Suggestions (each a switch in the mockup)

| Id  | What                                                                                                                                                                                                           | Limit                                                                                                                         | Cost                                                     | Verdict     |
|-----+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------------------------------------------------------------------------------------------------------------------+----------------------------------------------------------+-------------|
| A   | The right column becomes its own pane: =position: sticky; top: 0=, as tall as the window body (=100cqh= with the body as a size container), a flex column; heading/chips/filter take what they need, the table's =.mb-dg-vwrap= takes the rest (=flex: 1; max-height: none=) | the left column's tables keep 460 px                                                                                          | CSS only, nothing on the filter/sort/render path        | recommended |
| B   | Fill to the bottom: a =ResizeObserver= stretches the last table of each column to the window's bottom edge                                                                                                      | a table starting below the bottom edge (Recordings on the event window) can't fill anything (240 px minimum); right column scrolls away | one observer, one measurement per resize                | option      |
| C   | Proportional: =max-height: max(240px, 62cqh)= on every table                                                                                                                                                   | two tables in one column push the second off screen; the right table still stops short of the bottom                          | CSS only                                                 | weak        |
| D   | A drag grip under each table (drag, double-click resets, ↑/↓ by 20 px), height remembered per table id                                                                                                          | nothing grows by itself                                                                                                       | a few pointer handlers, one saved number per table      | add-on      |
| A+D | A for the right column, D's grips on the left column's tables                                                                                                                                                  | two behaviours side by side                                                                                                   | both                                                     | option      |

Under 640 px (one column) every variant keeps today's 460 px tables.
