** Answer (2026-10-06, branch =feature/jl-support=)

Done as the opt-in pageType =jl-list=. The new setting is
=sa_enable_jungleland= (⚙️ → 🌴 JUNGLELAND.IT), default OFF. Details:
=docs/claude/jungleland.md=, and the dated entry in =DEBUG-NOTES.md=.

- One button, "Bootlegs", turns the list's links into Title / Date / Year.
  - The trailing =(YYYY-MM-DD)= is cut off the title.
  - Year comes from the date. The undated "others" entries have none.
  - Links open the artwork page in a new tab.
  - Nothing is fetched; the list is one page.
- Decided on 2026-10-05: list.htm is normally the narrow left frame of
  =artwork.htm=, and the script stays out of that frame. It works on
  list.htm opened as its own tab.
- Shared with springsteenlyrics.com:
  - the detection loop's host comparison (=_foreignHost=);
  - the table CSS (=_ensureForeignTableStyle()=).
- Tests:
  - =tests/fixtures/jl-list.spec.js=, with its fixture built by
    =scripts/build-jl-fixtures.py=;
  - one =@include= test;
  - =scripts/mutations/jl-support.json=;
  - the live =@extended= spec =tests/live/jl-list.spec.js=, which covers the
    whole real page.
