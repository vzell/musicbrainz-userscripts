About this show

Broadcast on KMET-FM radio. Remarkable setlist includes the premieres of "Point Blank", "Rave On" and "Heartbreak Hotel". Another live debut "Independence Day" is performed solo on piano for only time on the tour. "Point Blank" features different lyrics to later versions and is played slightly differently. Also includes the first known tour performances of both "Twist And Shout" and "Raise Your Hand". "Night" is dropped for the first confirmed time on the tour. This show is widely seen as one of the great Springsteen shows of all time.

M1 · how it is built

  • One button, “Event”. Nothing changes on the page before it is pressed, as on every pageType.
  • One parse of the page (taken once) feeds the head, the tables and the existing hover preview, so the card and the page never disagree.
  • Head: byline, “About this show” from the gignote, Details cards, the picture section. Same component as a MusicBrainz release or a Discogs release page.
  • Tables appear only when the page has that data. Each is filterable, sortable and in the 📊 dropdown like any other.
  • Pictures are typed by filename, never by guessing: 19780707_CliffBreining_01.jpg → Photo by Cliff Breining.
  • The wiki page is kept below, closed, under its own heading. Click the heading to try it.
  • A recording, rehearsal, interview or nogig page gets the same layout; nogig adds a Cancelled table, recording renames On stage to In studio.

M4 · how it is reached

  • In the hover window of any Brucebase page: a “History” section, closed. It loads on opening, never on hover.
  • On our detail pages: a “changes” entry in the ☰ menu opens the same window.
  • The look is Discogs': the revision list, “View changes”, two columns old/new, the legend, “Only what changed”.
  • The diff is ours: lines matched first, words marked inside a changed line. Wikidot's own inline diff is used instead if the probe shows it is cleaner to read.
  • First a small probe you run logged in and logged out records what the four history modules answer (status and shape only, never your name or cookies).

Questions before Phase 1

  1. Setlist shape (M1).One table with a Set column (Soundcheck / Show / Encore) — recommended: one filter, one sort, a premiere filter across the whole night; or one table per set.
  2. Storyteller (M1).A table Moment / Song / Words, filterable by song — recommended; or a closed text section. Eyewitness stays a closed text section either way.
  3. Photographers (Filenames).A group per photographer inside Photo — recommended; or one Photo group with the credit in the caption only.
  4. History signed out (M4).Show “Sign in to Brucebase to see the history” — recommended, so it is clear why it is empty; or leave the section out.
  5. The wiki's page below (M1).Closed by default — recommended, our head and tables already carry the content; or open.
  6. Song titles.MusicBrainz case through the existing setting sa_foreign_mb_titles, the wiki's capitals as the hover text — recommended; or the wiki's capitals.
