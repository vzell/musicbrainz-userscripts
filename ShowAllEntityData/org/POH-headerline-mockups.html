What changes

P1

Every step a way back

recommended

Each step of the path is a button. A click shows that step again and drops the steps after it, which is what ← Back pressed several times would do. Nothing is fetched: the step's window comes from memory. The step shown now is plain text.

"…"
A button. It opens a menu of the hidden steps, oldest first, each with its glyph, kind and name. The menu also lists the visible steps, greyed, so the whole path is in one place.
Keys
Backspace and Alt+← stay as they are.
P2

A glyph before every step

recommended

MusicBrainz steps get MusicBrainz's own entity glyphs, the ones the table headers already use. Discogs steps get the glyphs you listed. Steps of other kinds (a Discogs search, a help article, an image set) get a small Discogs mark.

P3

Two rich cards

recommended
On a step
That entity's own card, the one its link shows on the page. It is already in memory, so resting on it asks nothing. Its foot says "Click: back to this step".
On a glyph
The documentation card: MusicBrainz's /doc/<Kind> page with its /doc/Style/<Kind> page linked in the foot, or Discogs' Database Guidelines article. Both come from readers we already have, with their usual rules. A click or Space reads the page in this window, and ← Back returns.

P5

Discogs: ✎ Editing history

recommended

A Discogs release window gets the button, without the ▾ menu. A click (or H) shows the release's history in the window, as "View changes" does from a submissions page today. Masters, artists and labels get it only if a probe finds a history page for them.

Decided (vzell, 2026-10-28)

Q1. Does a step read its kind or its name?

Both, as a setting. A step reads the entity's name by default ("The Angel"), cut at about 16 characters with the whole name in its card; the setting switches every path to kinds ("Recording").

Decided: a setting, default Name.
Q2. Discogs glyphs: emoji, or drawn glyphs?

💿 master, 📄 release, 🏷️ label, 👤 artist, 💬 user; the small Discogs mark for the other Discogs steps.

Decided: emoji.
Q3. How many steps before "…"?

Resize this page below 760 px to see two.

Decided: three, two in a narrow window.
Q4. Which Discogs articles?

Read off the Database Guidelines section you saved: Artist → 2. Artist (and 18. Updating An Artist Profile), Label → 4. Label / Catalog Number (and 19. Updating A Label Profile), Release → Overview Of Submission Guidelines For Releases (and 1. General Rules), Master → 16. Master Release, User → Community Guidelines, a release's history → 14. Updating Information (and 20. Voting Guidelines). The second article sits in the card's foot, where MusicBrainz's Style page does.

Decided: as listed.
