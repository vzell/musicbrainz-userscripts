Cards for links that leave the site

The popup engine previews MusicBrainz entities and the four Springsteen sites' own detail pages. Every link to another site still opens blind: the Wikipedia article in an annotation, the Brucebase review in the "URLs" sub-table, the YouTube playlist. These mockups show the same card and window for those links: a reader per known site, a generic reader for any other, the link's status, and what MusicBrainz itself knows about the URL.

Card texts are examples shaped like the real answers. Phase U0's probes replace them with measured fields before any code is written.

What is reused
The engine, unchanged

Card, delay, Ctrl gate, Space and Esc, the window with Extracted and Live page, ‹ ›, ⟳, ↗, drill-down, the cache. _dpLiveDocHtml() already cleans any site's HTML.

What is new
One source, many readers

_extSource() takes links to another origin; a reader per known site, a generic one for the rest. _extFetch() reads across origins, without cookies, one second apart per host.

What is asked of the user
One switch, off by default

A preview tells the linked site that someone looked. So it is opt-in, behind the Ctrl gate and the hover delay, and a pointer that moves on asks nothing.

How an external link becomes a card

The external source sits before the MusicBrainz one; the two never compete, because one takes only another origin and the other only its own.

Decisions

The open questions, answered on 2026-10-08.

  1. How long to keep an answer

    A week (168 hours), adjustable in the settings.

  2. A 404 or 410

    Kept for this page load only, in memory; never saved.

  3. Discogs

    Built (U0 found its web pages behind Cloudflare, its API open). An optional personal token raises its limit from 25 to 60 requests a minute; the token never goes into a config export.

  4. Generic reader's size cap

    512 KB.

  5. @connect

    Keep * and list each reader host beside it.

  6. Foreign hosts

    Every off-site link, under the same exclusions.

  7. First contact with a site

    Only on Space or a click, never from a hover: Tampermonkey asks once per site (U0, B1).

The Springsteen sites, from anywhere

The four sites' parsers take a page and a URL; nothing ties them to their own host except the fetch. Through _extFetch() a link to any of them gets the same card from MusicBrainz, and from each other's pages. IndexedDB is per origin, so a card cached on brucebase.wikidot.com is fetched again the first time on musicbrainz.org.

What moves

Only the fetch: _dpFetchText() (same origin, with the site's cookies) on the site itself, _extFetch() (anonymous) from anywhere else. The record, the card and the Live page fields stay the host's own.

No lyrics

The card counts verses and lines; it never quotes lyrics, in fixtures or specs either (docs/claude/detail-pages.md).

On the foreign hosts (U5)
  • springsteenlyrics.com's links to Brucebase get the Brucebase card
  • its share bar (facebook, reddit, x, whatsapp) gets nothing
  • jungleland.it's own host in capitals is still its own host

One new section after the MusicBrainz link previews. The Ctrl gate is the one every preview already follows; no new key replaces it.
