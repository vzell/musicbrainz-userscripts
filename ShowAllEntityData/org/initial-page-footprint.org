Asked 2026-10-20: "I want our userscript to be as non-intrusive as possible on
the IP of a supported MB PT … analyse and summarize what kind of features are
already injected besides our standard action buttons in the h1 line of a PT."

The IP is a supported MusicBrainz page BEFORE any action button is pressed
(nothing fetched, no consolidated table). Everything below runs there. Grep
anchors, not line numbers (the file moves on every commit).

Listeners with no visible effect on the IP: Alt-click on the event "#" cell,
the touch tracker, async-job hover, pagehide cleanup.

* Runs on the FRP only (after a button press or a disk load)

=makeH2sCollapsible()= and =_sbEnhance()= (collapsible h2s, the sidebar's
sections, counts, link groups, Open/Close-all), the sidebar collapse
(collapsed by default, =sa_sidebar_collapsed=), the release-tracks cover-art
section, =applyStickyHeaders=, =initStickyPageHeaders=, =initKeyboardShortcuts=
(Ctrl+S/L/,), =initNavigationGuard=, =performClutterCleanup=,
=stopOtherScripts=, the inline sidebar cards, event art, column resize and
visibility, density, stats.
