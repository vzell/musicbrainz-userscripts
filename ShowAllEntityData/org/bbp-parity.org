* Batch 1: the year table's name and anchor findings (next)

*Where:* the bb-year table. ▶ Pages already reads each row's event page (=_bbEvp*=, the record of =_dpParseBb()=), so batch 1 makes NO new request. The checks run on the row's own data plus that record (late data, as =bb-onstage-tab= does): =_bbEvpRenderCell()= marks the cell, live and source, and queues the row.

*The findings, through the add-finding skill:*
1. =bb-name-mismatch= (error) on the Event cell: the year page's heading differs from the event page's title after =normalizeDetailName='s rules.
   - Rules to port: "(The)" moved before the comma, " - " after the date, upper case.
   - "(early)", "(late)", "(afternoon)" and "(evening)" are a variant, not an error: a warn finding of its own, or none. *Ask vzell.*
2. =bb-anchor-date= (warn): the row's anchor does not start with the date's DDMMYY. No request at all.
3. =bb-anchor-link= (error): the event page's "Info & Setlist" link points to another anchor or another year (1949-64 aware).

4. =bb-title-spaces= (warn), added by vzell on 2026-11-14 ("findings should actually also show up as findings later on in our userscript").
   - *What it flags:* a Brucebase title with two blanks in a row, or a blank before a comma.
   - *Known case:* "2026-08-28 Stone Pony (The), Summer Stage,  Asbury Park, NJ", found by =scripts/probe-bruceparser-title-rules.py=.
   - *Cost:* no request. It reads the row's own title (Event cell, any bb-* list's title), the head's h1 and the window's title.

*Decisions (vzell, 2026-11-14):*
1. *The early/late variant is a WARN finding* of its own: "(Early)", "(Late)", "(Afternoon)", "(Evening)" after an otherwise equal name. Call it e.g. =bb-name-variant=; it is not an error.
2. *The name check uses the RAW Brucebase heading and title*, before =sa_foreign_mb_titles= / =sa_foreign_typography= restyle them. Keep the raw text in the cell's data (a =data-mb-bb-raw-*= attribute, as =data-mb-bb-entry= already does), never the render-tail text.
3. *The anchor postfix is checked too:* =bb-anchor-postfix= (warn), for when the a/b/c postfix of the year page's anchor differs from the one in the event page's address. BruceParser's =differences-date-postfix-detail-and-year.txt= has 1,352 lines, so expect many rows. The probe must count them first; if the count looks wrong, check the rule against the report before shipping.
