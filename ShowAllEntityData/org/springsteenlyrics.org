*** Answer (2026-10-05, branch =feature/sl-all-categories=, no code change)

Interactive mockups (private Artifact):
https://claude.ai/artifact/NYiaHNnv5y4HnCM5qAb6g6

Live probe (15 read-only GETs, 2026-10-05):
- Collection filters COMBINE on the server: album 1315 → =f_format=12i= 539
  → plus =f_country=USA= 125; =category=all&f_range=1980,1985= 1076 → plus
  =f_format=12i= 346. Correction (found while building the bar): on a
  FILTERED page the site's own links carry the active filter along, and the
  active chip is red (=label-danger=) with an href that removes it. The
  snapshots analysed above were all unfiltered.
- Bootleg filters do NOT combine: =f_title=born= and
  =f_title=born&f_version=soundboard= both give 73; =category=aud_live1975&f_date=…=
  ignores the date (487). =f_date= needs a full date: =1975-08-15= → 21,
  =1975-08= and =1975= → 0.
- The bootleg date form's =checkForm()= reads =form.filter_date=, but the input
  is =f_date=, so the check throws and never runs.
- Bootleg list pages mark no category as current, and the Statistics counts
  drift from list totals (544 vs 487 for Live 1975-1977).

Recommendation, in order:
1. A one-line scope bar on collection pages (searchable Category / Format /
   Country / Album / Year / Copies combo boxes), built from the page's own
   =.element-buttons= links, which stay in the DOM hidden by a class.
2. A grouped category picker with a current mark; an era ruler for bootlegs.
3. After a fetch, the same controls set column filters instead of reloading.
4. One bootleg search box that picks the field and normalises dates.
5. =bootlegs.php= via =@include=: navigation and search only, plus harvesting
   the Statistics counts. Defer "show all bootlegs" (~7,300 rows, ~82 pages).
6. Formats: one merged glossary in the Format menu, Liner-notes tooltips on
   cells, then a Media/Units column extractor.

Decided (2026-10-05):
- Compact navigation is a SETTING (new =sa_*= key, under the
  springsteenlyrics divider), not always on.
- Option B (scope bar) on bootleg list pages too, not the toolbar menus.
- Category counts are EXACT: record the "Showing items … of N" total of each
  list as it is visited (GM storage), never the landing page's drifting
  Statistics numbers.
