** Decisions (2026-09-24) and what shipped

Options were put up as ASCII mockups and the chosen shape was *two menus*:
=📦 Data ▾= and =🛠 View ▾=, with =⚙️= and =❓= staying pinned. Items 1, 3, 4, 5
and 6 landed on branch =action-button-redesign=; item 2 is deliberately a
second branch.

| item | decision                                                                                     | state                   |
|------|----------------------------------------------------------------------------------------------|-------------------------|
|   1. | =↔️= / =👁️= glyph-only, in the h2 immediately before =#mb-filter-container=                    | DONE                    |
|   2. | =❓= opens the GitHub page; *Shift-click still opens the in-script dialog*; hand-written =.md= | branch 2, not started   |
|   3. | =🎹= joins =🛠 View ▾=; =⚙️= stays pinned beside =❓=                                           | DONE                    |
|   4. | Density / Statistics / Barcode into =🛠 View ▾=; Export into =📦 Data ▾=                       | DONE                    |
|   5. | Save / Load are rows of =📦 Data ▾=, so they cost one slot between them                        | DONE                    |
|   6. | =tests/support/toolbarMenu.js=; 9 call sites migrated; 2 new specs + 2 mutation lists          | DONE                    |

Not in the original list, added because that page has the widest heading the
script renders: =artist-releasegroups=' four discography views became
=📀 Discography ▾=, whose button *names the active view*. The flat run could
only tint the active button, which told the user nothing until they had looked
at all four.

On item 2, the one deviation from the text below: the in-script dialog is kept
behind Shift-click rather than removed. Its quick-filter search is genuinely
useful and it is the only route that works with no network.

Mechanism, traps and test surface: see =CLAUDE.md='s "The h1 toolbar is two
pull-down menus plus two pinned buttons" and "↔️ Resize and 👁️ Visible live in
the h2" sections, and =DEBUG-NOTES.md='s 2026-09-24 entry.
