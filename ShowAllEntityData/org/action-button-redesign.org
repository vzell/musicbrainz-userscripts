behind Shift-click rather than removed. Its quick-filter search is genuinely
useful and it is the only route that works with no network.

*Item 2, as built.* =ShowAllEntityData_HELP.md= is hand-written rather than
converted — the request says "probably needs a .md conversion", and a
transcription of 2448 lines of hand-laid-out plain text would have carried
across three years of accumulated resyncs along with their layout. It is about
a third of the length, organised by what the reader is trying to do, with the
reference detail in =<details>= sections. The =.txt= is retired; the mirror
keeps serving it until users have updated past the rename.

Two things the item did not ask for and got anyway, because the route to GitHub
made them necessary rather than optional:

  - the in-script dialog needed a Markdown renderer, since it used to drop the
    file into a =<pre>= and Markdown in a =<pre>= shows its own syntax;
  - =scripts/check-publish-ready.py= now fails on a companion file the
    published script fetches but the mirror LACKS, not only on one that
    differs. That is exactly the way this change could have shipped broken —
    script published, renamed help file not.

shortcut is real. Fixed here, since this branch re-drifts those baselines
anyway.
