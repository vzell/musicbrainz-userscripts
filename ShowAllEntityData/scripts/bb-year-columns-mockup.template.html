Brucebase year columns

The year table (bb-year) has each entry's date, place, type and tour from the year page. Everything else lives on the event's own page: who was on stage, which tabs have content (a recording, Storyteller, media, eyewitness reports), the pictures. This mockup adds those columns to the real table and shows them filling in, one event page a second, the way the link previews read the same pages. The new columns are green.
