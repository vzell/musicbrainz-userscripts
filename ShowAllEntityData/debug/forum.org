# [VZ: MusicBrainz - Show All Entity Data In A Consolidated View With Filtering And Multi-Sorting Capabilities](https://github.com/vzell/mb-userscripts/tree/master?tab=readme-ov-file#mb_show_all_entity_data)

## Changes since last version

### Enhancements

* **Keyboard shortcuts** completely reworked --- direct Ctrl+ shortcuts are now disabled by default to avoid accidentally hijacking browser or OS key combinations. All actions are instead available through the Ctrl+M prefix menu: press Ctrl+M followed by a single letter to trigger any action. The prefix tooltip lists everything available. For users who prefer direct shortcuts, the old behaviour can be re-enabled in settings. The shortcuts for the keyboard help overlay and barcode highlight are now configurable.
* **Rendering** doesn't show the "Page unresponsive" dialog anymore on large tables
* **Auto-resize** columns got a progress overlay and is much faster on large tables --- when the script measures and fits column widths on large tables, it now shows a progress overlay with elapsed time and an estimated time remaining instead of just freezing the page (e.g. x15 on a 8100 rows table https://musicbrainz.org/artist/70248960-cb53-4ea4-943a-edb18f7d336f/releases )
* **Filtering** is significantly faster on large tables --- several rounds of optimisation (caching, smarter matching order, adaptive typing delays) cut filter response times noticeably on tables with thousands of rows
* **Status bar** completely redesigned --- the progress line at the top now has separate segments for cover art loading, relationship loading, and general info, each with its own hover tooltip showing detailed timing and counts
* **Alternating shade banding** (the subtle colour striping that shows where sorted values change) now also works when *sorting by a single column*, not just multi-column sorts
* **Cover-art thumbnails** load in a smarter order --- inline thumbnails in the title column are now fetched before the smaller icons in the CAA/EAA columns, so the most visible images appear first
* **Collapsed artwork** cells show a "hidden match" hint --- if a row is hidden inside a collapsed cover-art stripe but matches your filter, the expand button turns yellow with a red marker so you know there's a match inside
* **Sort by text length** --- Alt+clicking a sort arrow now sorts that column by the length of each cell's text, useful for spotting unusually long or short values
* **Event columns** got smarter --- event entries now split out separate columns for Event Type, Event Country, and Additional Info, making it much easier to filter and sort large event lists
* **Relationship icons** now show *rich tooltips* --- hovering over a relationship icon displays a proper popup with the full relationship details, highlighted to match your active filter
* **Relationship icons** *highlight* when your filter matches --- if your filter finds a row because of something in the Relationships column, the specific matching icons are outlined in red so you can see exactly why the row matched
* **IndexedDB cache statistics** added to the Stats panel --- shows how many relationship records are stored locally, how much space they use, and when they were last accessed
* Added support for **Ratings pages** --- your /user//ratings pages (and per-entity variants like /ratings/recording) now load all entries at once with full filtering and sorting, including the editor name, entity type, and star rating columns
* Added support for **entity-level Ratings pages** --- the /work//ratings and similar pages that list everyone who rated a specific entity are now supported as well

### Fixes

* **"Save to disk"** now preserves the correct column headers when saving at the large-table render-threshold prompt --- previously the saved file could contain the wrong header names
* **Column resize** is much more reliable --- a run of fixes addressed resize minimum creep, line breaks appearing in disambiguation comments during resize, and incorrect widths on initially-collapsed sub-tables

# [VZ: MusicBrainz - Show All Entity Data In A Consolidated View With Filtering And Multi-Sorting Capabilities](https://github.com/vzell/mb-userscripts/tree/master?tab=readme-ov-file#mb_show_all_entity_data)

## Changes since last version

### New pages supported

* **Report pages** --- the full [/reports](https://musicbrainz.org/reports) index (all 117 reports, in 14 categories) and every individual report page now load, filter and sort like every other page this script handles, including inline cover-art thumbnails where a report lists releases or events, and extra date/time and text-length columns on reports that have a "Last edited" or "Annotation" column.
* **Your Applications page** --- [/account/applications](https://musicbrainz.org/account/applications) (your OAuth2 authorized apps, and any apps you've registered as a developer) is now consolidated into one filterable table.
* **Edit-listing pages** --- a big one: search results for edits, edits on a specific entity, subscribed edits, your own edits (open or all), and the "recent notes left on your edits" page are all now supported. Each edit becomes a proper table row, edit type and open/closed state get a colour (matching the well-known "Colourful Edits" userscript's palette, even if you don't have it installed), old/new value changes are colour-coded, and long edit details/notes can be collapsed. Edits tied to a specific release also get a small cover-art thumbnail.
* **Auto-editor elections** --- both the [/elections](https://musicbrainz.org/elections) overview and individual election pages.
* **Genre list, Instrument list, Edit Types documentation, and CD stub pages** --- [/genres](https://musicbrainz.org/genres), [/instruments](https://musicbrainz.org/instruments), [/doc/Edit_Types](https://musicbrainz.org/doc/Edit_Types), and both the CD stub browsing list and individual CD stub pages all get the same filtering/sorting treatment.
* **Privileged user accounts** --- the [/privileged](https://musicbrainz.org/privileged) page listing auto-editors, relationship editors, bots, and other special account types.
* **musicbrainz.eu mirror** --- the script now works there too, not just musicbrainz.org.

### Enhancements

* **Filter dropdown multi-select** --- the little 📊 dropdown that lists every value in a column now lets you tick several values at once instead of only picking one.
* **Collapsible long-text columns** --- free-text columns like "Annotation" can now be collapsed behind a "show more/less" toggle instead of stretching the row, with a configurable preview height. Wiki-style sub-headings inside an annotation stay individually collapsible too, with their own colour setting.
* **Auto-expand annotations on entity pages** --- optionally, a long native Annotation on an entity's own page can now expand automatically instead of needing an extra click (off by default).
* **Smarter Location/Area columns** --- the "Area" columns now split more usefully into a Locality (city) and Region (state/county) part instead of one combined value, and play nicer with popular flag-icon userscripts (Canadian Province Flags, More Flags Everywhere, etc.).
* **Optional flag icons in the filter dropdown** --- Country/Area/Location-style columns can now optionally show the same little flag icon in the filter dropdown as in the table itself (off by default).

### Fixes

* Sorting no longer gets confused by hidden cover-art/event-art markers, so tables with inline thumbnails sort correctly again.
* Sorting now applies consistently across every row of a merged release-group discography view, instead of only part of it.
* Several rendering glitches on report pages are fixed (missing section headings, broken formatting when an annotation contained wiki-style headings, wrong or missing cover-art icons).
* Column filtering on edit-listing pages no longer highlights the wrong column.
* A handful of small bugs in the collapsible-column toggles are fixed (wrong item counts, a toggle that stopped responding after being clicked once).
* Several dialogs (Settings, Save/Load to Disk, Statistics, Export, and others) now display correctly on the Applications page, which previously showed them broken/unstyled due to MusicBrainz applying stricter security rules there.
* Minor: column headers starting with a number (e.g. "1st seconder" on election pages) no longer render with the digit stripped off.
* Minor: fixed a column-alignment issue on pages when also using the "MusicBrainz Nuclear Tags" userscript.
