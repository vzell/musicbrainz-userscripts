## 9.99.746 — 2026-07-31

**📝 Docs**

- Resynced ShowAllEntityData\_HELP.txt against every user-facing change since 9.99.675, and against the live keyboard-shortcut/settings code as ground truth. ## 9.99.728 — 2026-07-31

**🐛 Fix**

- Country column unique-values filter dropdown (📊): the flag icon next to each country name now renders identically to the flag in the table cell. Previously only the span's CSS class was copied into the dropdown clone, which relies on MusicBrainz's own stylesheet cascading correctly wherever the clone lands — the dropdown panel sits outside \#content/table.tbl and in a smaller font-size context, so the flag could come out looking flatter/blanker than the real one.
